Help

If something isn't working, start here.

An upload failed

Open it in the Library and choose Retry. Check that the file is a PDF, PPTX, MP3 or MP4 and isn't password-protected or empty.

A file is still processing

Long recordings take longer. You can leave the page; progress continues and the Library updates when you return.

An answer says the lecture doesn't cover it

That means the processed material has no passage that answers the question. Try rephrasing, or ask for the separately labelled general-knowledge explanation.

I can't generate an AI quiz

AI quizzes need an AI service configured on the server. Your own question bank works without it.

I forgot my password

Use "Forgot password?" on the sign-in page. Reset email needs the server's email settings to be configured.
